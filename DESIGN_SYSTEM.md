# ReddTools Design System

Derived from Kodosumi (design-kodosumi.md) — Technical Minimalism.

## Colours
- Background: #f5f5f5
- Surface: #ffffff
- Surface dim: #ebebeb
- Text: #000000
- Text muted: #5b5b5b
- Text faint: #999999
- Border: #d0d0d0
- Cyan accent: #00c2ff
- Green accent: #0afa14
- Orange accent: #ff6400

## Typography
- Font: Inter (400, 500, 600)
- Mono: IBM Plex Mono (400, 500)
- Display: 64px / 400 / -0.02em
- Headline: 28-40px / 400
- Title: 20px / 500
- Body: 16px / 400 / 1.5
- Label: 11-14px / 400-500 / mono for badges

## Spacing
- Unit: 8px
- xs: 4px, sm: 12px, md: 24px, lg: 40px, xl: 64px
- Container max: 1440px
- Grid: 12 columns

## Radius
- Cards/inputs: 4px (0.25rem)
- Buttons: 9999px (pill)
- Badges: 4px

## Elevation
- Card: 0 1px 2px rgba(0,0,0,0.06)
- Card hover: 0 3px 8px rgba(0,0,0,0.15)
- Input focus: 0 0 0 3px rgba(0,194,255,0.1)

## Components
- Primary button: black bg, white text, pill, 40px height
- Secondary button: transparent, 1px border rgba(0,0,0,0.1), pill
- Card: white, 4px radius, 1px border rgba(0,0,0,0.04), subtle shadow
- Input: #fafafa bg, #d0d0d0 border, 4px radius, cyan focus ring
- Badge: transparent bg, colored text, mono, 4px radius
